# Signal TV — Windows antigo

A configuração usa Electron 22.3.27 e Node.js 24 no GitHub Actions.

1. Envie o conteúdo desta pasta para o repositório GitHub.
2. Abra **Actions**.
3. Selecione **Build Signal TV for Windows**.
4. Clique em **Run workflow**.
5. Depois, descarregue o artefato `signal-tv-windows`.

Nota: o projeto deve conter a pasta `src` com o código React para a compilação funcionar.
